    - Strengthened `goal_alignment_states` RLS and scope constraints so rows must belong to the authenticated user's conversation and story/character rows cannot use invalid null-scope combinations.
    - Rejected invalid evaluator `goalKind`, `signal`, and `intensity` values in `evaluate-goal-alignment` instead of coercing malformed output into real updates.
