When edge/model responses deviated, users saw a no-op.
  plan: "Harden the shared enhance call stack used by Story Builder and Character Builder: explicitly pass session Bearer tokens to chat edge invokes, parse multiple valid assistant content shapes, preserve retries, and surface user-visible error feedback instead of console-only logs."

    • Added explicit `supabase.auth.getSession()` access-token retrieval in world/character AI enhance services and passed Bearer headers to `chat` invokes.
    • Expanded assistant response parsing to support string, object, and array content payload variants before extracting final text.
    • Improved edge error propagation so detailed response messages are preserved for diagnostics.
    • Added visible `sonner` toast feedback in Story Builder + Character Builder enhance handlers so failures are actionable instead of silent.
    • Kept existing enhance mode behavior (`precise` / `detailed`) and field wiring intact.
