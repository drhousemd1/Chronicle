    • Added an explicit AI speaker fallback in `resolveRenderedSpeakerName()` so AI-rendered blocks always return a deterministic name (`first AI character` or `Narrator`) instead of falling through.
    • Reconciled side-character personality-trait handling with the current live contract by normalizing extracted trait updates into `string[]` instead of forcing `{ label, value }[]` casts in one branch.
    • Added explicit regenerate guards so the regenerate path now exits safely when the target conversation or target message is missing instead of constructing a follow-up payload from possibly undefined state.

    • Re-ran `npm run ship-check` after the cleanup and confirmed the repo is back to a clean pass: typecheck, lint, and production build all complete successfully.
