  changes: |-
    Implemented a coherence-focused prompt hardening pass:
    • Expanded the main system instruction with a new SCENE LOGIC & CAUSAL CONTINUITY block that tells the model to preserve established physical facts, stop replaying resolved beats, respect available resources and environmental constraints, and answer direct questions when an AI character reasonably can.
    • Added NATURAL PROSE & DIALOGUE guidance forbidding literal trope labels in output, discouraging machine-like phrasing, and capping em-dash use so the prose reads more human.
    • Added CHARACTER SHEET USAGE rules so the model treats cards as reference rather than a checklist, reducing repeated body-stat and clothing recitation.
    • Strengthened the regeneration directive to preserve resolved scene facts, forbid invented props/obstacles, keep the same timeline, and answer direct questions in refresh responses.
    • Replaced the previous 'flexible realism' language that effectively allowed nonsense logic with a story-flexible but logic-strict rule set.
    • Updated the Master Prompt Snapshot export so it now reports the actual hardcoded temperature (0.55) and correctly states that random style hints are disabled in the current runtime.
