    • Refactored gallery NSFW preference handling into a shared `useGalleryNsfwAccess` hook so toggle-driven reveal and blurred-card reveal follow one approval path.
    • Split the Chronicle-styled 18+ prompt into a reusable `GalleryNsfwAgeModal` and kept `GalleryNsfwToggle` focused on display/control only.
    • Updated both the standalone `Gallery` page and the in-app Gallery tab in `Index.tsx` to use the shared access hook plus the shared age-confirm modal.
    • Updated `GalleryHub` so clicking a blurred NSFW story card or its Play action requests NSFW approval first instead of opening the detail view immediately.
    • Preserved the approved behavior after confirmation: `Show NSFW` turns on automatically and the intended story flow continues from the same click.
    • Preserved the cancel path: closing or declining the prompt keeps NSFW hidden and prevents the story modal from opening.
