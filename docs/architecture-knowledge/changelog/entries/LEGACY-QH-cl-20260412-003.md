    • Removed the per-turn random style-hint append from `generateRoleplayResponseStream()` so the final user message now contains only the session wrapper, optional length directive, and actual user/regeneration content.
    • Lowered the hardcoded xAI chat temperature from `0.9` to `0.55` in the `chat` edge function to reduce high-variance scene jumps and clipped nonsense dialogue.
    • Intentionally left the rest of the prompt assembly, runtime directives, and history serialization untouched so follow-up testing can measure whether weighting reduction alone improves logic and continuity in Chronicle's main roleplay flow.
