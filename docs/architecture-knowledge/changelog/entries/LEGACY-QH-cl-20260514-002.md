    - Replaced the character-update extractor's cabin/fireplace and named relationship/goal examples with generic placeholders.

    - Added a tested parser for extracted goal update values.
    - Preserved existing goal status when API Call 2 does not explicitly send `current_status`.
    - Applied `complete_steps` without allowing `new_steps` text to become an existing goal's status.
    - Kept task-level goal filtering centralized so short scene logistics are still rejected as saved goals or generated milestone steps.

    - Added goal parser coverage for malformed tactical `new_steps` strings and durable milestone filtering.
    - Added extractor-prompt coverage for the positive milestone guidance and generic structural example.
