    • Updated `GalleryHub` and `GalleryCategorySidebar` so NSFW story-type filtering respects the toggle state and avoids presenting unavailable NSFW filter options when hidden.
    • Updated gallery cards so NSFW cover images are visually masked when the user has not opted in, while still keeping the story in the grid flow.
    • Relaxed review-data typings in `gallery-data.ts` to better reflect partially populated review records used by the revised review flow.
