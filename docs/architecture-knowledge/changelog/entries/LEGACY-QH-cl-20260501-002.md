    - Upgraded the physical continuity language so threshold/doorway locks are framed as binding scene facts, not background flavor.

    Updated `supabase/functions/chat/index.ts`:
    - Strengthened derived position-lock facts so unresolved user-controlled threshold states stay visibly unresolved until the user moves them.
    - Tightened local planner fallback guidance and writer instructions so second-speaker blocks must add new information, conflict, or pressure instead of echoing solved logistics.
    - Added explicit writer guidance to let the current beat land before jumping into a new mini-plan, and to treat private thoughts as meaningful withheld cognition rather than decorative emotion captions.
