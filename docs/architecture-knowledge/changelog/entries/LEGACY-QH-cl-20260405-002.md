  problem: The existing review flow created too much friction for end users and visually diverged from Chronicle's modal language. At the same time, completely removing the detailed category ratings would have thrown away the structured creator-feedback layer the product still wants. The modal needed to feel fast by default without eliminating deeper optional feedback.
  plan: Keep the change scoped to the shared review flow. Restyle the modal to match Chronicle's dark slate-blue modal system, move story/spice into a low-friction quick-rating section at the top, hide the detailed category ratings inside an optional expandable Additional Feedback section, keep the text comment as a separate optional note field, and update submission/rendering logic so partial reviews remain safe.
  changes: |-
    Implemented a focused review-flow rework:
    • Rebuilt `ReviewModal` to use the Chronicle modal shell, Chronicle recessed textarea styling, and raised action buttons.
    • Kept the fast `Quick Rating` block at the top with story stars and optional spice flames.
    • Restored the detailed category star ratings, but moved them into an optional collapsible `Additional Feedback` section so they do not clutter the default experience.
    • Trimmed the optional category set to `Concept Strength`, `Motivation / Tension`, `Worldbuilding & Vibe`, `Replayability`, and `Character Details & Complexity` to keep the expanded section shorter and more usable.
    • Added a fixed viewport-safe modal height so the review modal body remains scrollable when Additional Feedback is expanded.
    • Kept Additional Feedback collapsed by default and suppressed legacy mirrored category values so old all-5-star review data does not appear as intentional detailed feedback.
    • Added outside-click dismissal for the nested review popup while explicitly stopping propagation so it returns to `StoryDetailModal` instead of closing both modal layers.
    • Kept the freeform text comment as a separate optional note field instead of conflating it with Additional Feedback.
    • Kept submit gated only by quick rating input: the reviewer can submit once story or spice is set.
    • Updated the client review submission helper so detailed feedback categories submit independently from the quick story rating instead of silently mirroring story score into every category.
    • Passed story type into the review modal from `StoryDetailModal` and kept review rendering tolerant of missing story/spice values so SFW or partial reviews display cleanly.
    • Updated gallery and Your Stories guide docs to describe the quick-rating + expandable-feedback flow.
