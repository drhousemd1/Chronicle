# Chronicle project references

For product orientation when requested, use `chronicle-onboarding`. The Knowledge Base's section registry is `docs/architecture-knowledge/manifest.json`; consult the relevant product documentation and current source for the assigned task. Global working preferences apply.

For UI design or styling, use the relevant region in the **Chronicle UI Guide**. `docs/ui-guide/README.md` explains how to retrieve its Markdown and images directly for a coding task.

Current Work is retired. Records under `docs/current-work/` are historical reference, not active assignments or workflow instructions. Record Issues and meaningful completed changes independently when relevant; finding an issue does not automatically start a project.
